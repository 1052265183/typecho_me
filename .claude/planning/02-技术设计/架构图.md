# Typecho 架构图

> 模块关系图。本文件与 `CLAUDE.md §1` 互补：CLAUDE.md 是文字描述，本文件是图。

## 顶层请求流

```
                   HTTP 请求
                      │
                      ▼
        ┌──────────────────────────┐
        │   index.php / install.php │
        │   admin/<page>.php        │
        └──────────────────────────┘
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
   config.inc.php   Widget\Init   Plugin::factory
   (若无→install)   ::alloc()      'index.php'
                                   →begin
                      │
                      ▼
              ┌─────────────────┐
              │  Typecho\Router  │
              │  ::dispatch()    │
              │  ::match()       │
              └─────────────────┘
                      │
            ┌─────────┴─────────┐
            ▼                   ▼
   Widget::widget()    Widget::widget()
   'Widget\Archive'    'Widget\Comments'
            │                   │
            ▼                   ▼
   var/Typecho/Widget.php（基类，对象池）
            │
            ▼
       渲染主题
   usr/themes/<theme>/
```

## 后台请求流

```
       HTTP → admin/<page>.php
                  │
                  ▼
        require admin/common.php
                  │  ← 鉴权 + Widget\Init::alloc()
                  ▼
        Widget\<PageWidget>::alloc()
                  │
                  ▼
            渲染后台模板
        （admin/ 下若干 PHP 页面）
```

## 关键模块定位

| 关注点 | 文件 |
|---|---|
| 请求入口 | `index.php` / `install.php` / `admin/login.php` |
| 核心基类 | `var/Typecho/Widget.php`（551 行） |
| 路由核心 | `var/Typecho/Router.php` |
| 数据库抽象 | `var/Typecho/Db.php` + `var/Typecho/Db/Adapter/` |
| 插件机制 | `var/Typecho/Plugin.php` + `var/Typecho/Plugin/PluginInterface.php` |
| 国际化 | `var/Typecho/I18n.php` + `var/Typecho/I18n/GetText.php` |
| 协议 | `var/IXR/`（XML-RPC + Pingback） |
| 工具 | `var/Utils/HyperDown.php`（Markdown）/ `AutoP.php` / `PasswordHash.php` |
| 表单助手 | `var/Widget/Helper/Form.php` + `Helper/Element/*.php` |
